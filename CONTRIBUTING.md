# Contributing to DedSec Project / Συνεισφορά στο DedSec Project

## English
Major new functionality and significant behavior changes must include new or updated automated tests.
Keep English and Greek project content synchronized where applicable.
Run `python -m pytest` and `ruff check .` before submitting a pull request.
Follow `SECURITY.md` for private vulnerability reporting.

## Ελληνικά
Κάθε σημαντική νέα λειτουργία και κάθε ουσιαστική αλλαγή συμπεριφοράς πρέπει να συνοδεύεται από νέα ή ενημερωμένα automated tests.
Το Αγγλικό και Ελληνικό περιεχόμενο πρέπει να παραμένει συγχρονισμένο όπου εφαρμόζεται.
Πριν από pull request τρέξε `python -m pytest` και `ruff check .`.
Για private vulnerability reporting ακολούθησε το `SECURITY.md`.
