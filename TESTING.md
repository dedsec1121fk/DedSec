# DedSec Testing / Δοκιμές DedSec

## English
Run the test suite from the repository root:

```bash
python -m pytest
```

Install development dependencies with:

```bash
python -m pip install -r requirements-dev.txt
```

The baseline tests do not execute operational DedSec tools. They perform syntax, structure, and safe contract checks.

## Ελληνικά
Τρέξε το test suite από τη ρίζα του repository:

```bash
python -m pytest
```

Εγκατάστησε τα development dependencies με:

```bash
python -m pip install -r requirements-dev.txt
```

Τα βασικά tests δεν εκτελούν τα operational εργαλεία του DedSec. Κάνουν syntax, structure και ασφαλή contract checks.
