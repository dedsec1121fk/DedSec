**Αναλυτικές τεχνικές λεπτομέρειες:** `DEDSEC_FULL_MAINTENANCE_HANDBOOK_EN.md` στον ίδιο φάκελο.

## Ποιος δημιούργησε το έργο

Η δημιουργία του DedSec Project αποδίδεται στον ιδιοκτήτη `dedsec1121fk`. Οι παρούσες οδηγίες περιγράφουν τη δομή του υπαρκτού κώδικα και έναν τρόπο να ξαναφτιαχτεί η ίδια αρχιτεκτονική από την αρχή. **Δεν είναι αποδεδειγμένο χρονολόγιο** όλων των αρχικών ενεργειών του δημιουργού. Δεν αποδίδουμε τη δημιουργία του έργου σε AI. Διατηρούμε τις υπάρχουσες αναφορές στους συντελεστές και στον υπεύθυνο των νομικών εγγράφων.

## Ανακατασκευή της αρχιτεκτονικής από την αρχή

1. Δημιούργησε τη βασική δομή: `Setup.sh`, `Setup-Termux.sh`, `Run.sh`, `Scripts/`, `Compat/`, `Important Documents/`, `tests/`, `.github/`.
2. Σχεδίασε το βασικό μενού σε Python (`Scripts/Settings.py`) με επιλογή γλώσσας, στυλ, προτιμήσεις χρήστη και εκκίνηση εφαρμογών.
3. Οργάνωσε το περιβάλλον Termux χρησιμοποιώντας `pkg`, ενώ στα Ubuntu/Kali/Linux Mint χρησιμοποίησε `apt-get` και το τοπικό Python `.venv`.
4. Πρόσθεσε τις εφαρμογές και τα παιχνίδια σε φακέλους κατηγορίας, με έλεγχο της έκδοσης Python και με ασφάλεια ως προς τα προσωπικά δεδομένα.
5. Δημιούργησε το DedSec OS ως τοπική υπηρεσία HTTP και διεπαφή HTML/CSS/JavaScript που περιέχονται στο `Settings.py`. Κάθε κουμπί πρέπει να συνδέεται σε λειτουργία JavaScript και, όταν απαιτείται, σε endpoint `/api/`.
6. Πρόσθεσε ελληνικά/αγγλικά κείμενα, αρχικά αρχεία νομικής αποποίησης, υποχρεωτική συγκατάθεση εγκατάστασης, tests και τεκμηρίωση.
7. Έλεγξε την πραγματική λειτουργία σε Termux και ξεχωριστά σε Linux. Μην βασίζεσαι μόνο στον έλεγχο σύνταξης.

## Υποχρεωτικοί νομικοί όροι στην πρώτη εγκατάσταση

Εκτέλεσε `bash Setup.sh`.

- `y` ή **Enter**: αποδοχή και συνέχεια εγκατάστασης.
- `n`: απόρριψη και άμεσος τερματισμός, χωρίς εκτέλεση εγκατάστασης. Επιτρέπεται νέα προσπάθεια αργότερα.
- `r`: εμφάνιση επιλογών ανάγνωσης.
- `re`: ανάγνωση όλου του αγγλικού εγγράφου.
- `rg`: ανάγνωση όλου του ελληνικού εγγράφου.

Τα αυθεντικά αρχεία είναι `Legal Disclaimer English Version.docx` και `Legal Disclaimer Greek Version.docx`. Τα αντίστοιχα `.txt` είναι αντίγραφα εμφάνισης για το τερματικό. Η αποδοχή αποθηκεύεται ανά χρήστη στο `~/.local/state/dedsec/legal-acceptance-v1.txt` ως hash των αυθεντικών εγγράφων· νέα έκδοση όρων απαιτεί νέα αποδοχή. Αν ο χρήστης δεν δώσει είσοδο (EOF), η εγκατάσταση απορρίπτεται.

## Συντήρηση Linux και Termux

```bash
bash Setup.sh --skip-system-update --required-only --no-run
./Run.sh
# Για έλεγχο των πακέτων στην τοπική Python:
./.venv/bin/python -c 'import flask, flask_socketio; print("OK")'
# Ανανέωση της ρύθμισης αυτόματης εκκίνησης:
./.venv/bin/python Scripts/Settings.py --configure-menu-autostart
```

Μην εγκαθιστάς πακέτα μέσω `sudo pip` στο system Python. Μην αλλάζεις το `git origin` από το επίσημο `dedsec1121fk/DedSec` σε άλλο αποθετήριο. Στο Termux χρησιμοποιείται η εγκατεστημένη Python του `pkg` και μπορεί να χρειάζονται εφαρμογές Android με άδεια χρήστη.

Τα προσωρινά logs της εγκατάστασης βρίσκονται στο `~/.dedsec/logs/`. Το backup του desktop αποθηκεύει το υπάρχον έργο τοπικά ως ZIP στο Downloads. Το Termux χρησιμοποιεί διαφορετική ιστορική λειτουργία μεταφοράς/backup.

## DedSec OS — σημεία που απαιτούν δοκιμή

- **Browser:** ορισμένοι ιστότοποι εμποδίζουν ενσωμάτωση σε iframe με CSP. Χρησιμοποίησε `Open External`.
- **Word:** μετά την επιλογή κειμένου δοκίμασε έντονα/πλάγια/υπογράμμιση, χρώμα και αποθήκευση. Η επιλογή κειμένου πρέπει να διατηρείται κατά το πάτημα των κουμπιών.
- **Scratchpad:** έλεγχος αποθήκευσης με επανάγνωση μέσω του API. Η διαδρομή εξαρτάται από το προφίλ.
- **Software Center:** στο Ubuntu απαιτούνται προσβάσιμοι κατάλογοι και ενδεχομένως `sudo`, όχι άδεια Android Storage.
- **Games:** επιβεβαίωσε με ποντίκι/πληκτρολόγιο τα Solitaire, Tic-Tac-Toe, Memory, Pinball, 2048, Connect Four σε πραγματικό browser.
- **Photo Studio:** χρησιμοποίησε `New canvas`, ενεργοποίησε Brush, αποθήκευσε την εικόνα.
- **Help:** πάτησε κατηγορίες, προτεινόμενα άρθρα, κουμπιά Help στα diagnostics.
- **Terminal:** κάποιες εντολές απαιτούν πραγματικό terminal/PTY· έλεγξε τυχόν διπλή εμφάνιση και τα σφάλματα JavaScript.
- **Tor / HTTP proxy:** δεν αποτελούν πλήρες VPN και δεν αλλάζουν αυτομάτως την IP όλων των εφαρμογών.

```bash
bash -n Setup.sh Setup-Termux.sh Run.sh Compat/legal_consent.sh
python -m compileall -q Scripts tests
python -m pytest -q tests
```

Για κάθε σφάλμα έλεγξε το αντίστοιχο αρχείο, αναπαράγαγε το πρόβλημα, διόρθωσε τον κώδικα, πρόσθεσε test και επανέλεγξε σε Ubuntu, Linux Mint, Kali και Termux. **Το ότι περνάει ένα static test δεν αποδεικνύει ότι το GUI λειτουργεί.**

Για την πλήρη διαδικασία ενημερώσεων, rollback, ασφάλεια δεδομένων, δομή API, οδηγίες παιχνιδιών και πίνακα σφαλμάτων, διάβασε το αγγλικό αναλυτικό εγχειρίδιο.
