# Security Policy — DedSec Project / Πολιτική Ασφάλειας — DedSec Project

## English
Use DedSec Project only on systems you own or have explicit permission to test.

Report undisclosed vulnerabilities privately through GitHub Security → Report a vulnerability when available.
Do not open a public issue for an active undisclosed vulnerability.

An initial response will be provided within 14 calendar days for valid security reports.

Security-sensitive code should use established cryptographic libraries, salted password derivation such as PBKDF2-HMAC-SHA256 where applicable, and cryptographically secure randomness.

## Ελληνικά
Χρησιμοποίησε το DedSec Project μόνο σε συστήματα που σου ανήκουν ή για τα οποία έχεις ρητή άδεια δοκιμής.

Αναφορά μη αποκαλυμμένων vulnerabilities πρέπει να γίνεται ιδιωτικά μέσω GitHub Security → Report a vulnerability, όταν είναι διαθέσιμο.
Μην ανοίγεις public issue για ενεργή μη αποκαλυμμένη ευπάθεια.

Για έγκυρες security αναφορές θα δίνεται αρχική απάντηση μέσα σε 14 ημερολογιακές ημέρες.

Security-sensitive code πρέπει να χρησιμοποιεί καθιερωμένες cryptographic libraries, salted password derivation όπως PBKDF2-HMAC-SHA256 όπου εφαρμόζεται, και cryptographically secure randomness.
